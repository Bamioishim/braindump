# Brain Dump → Done — TODO

## Core transformation flow
- [ ] A user can paste an unstructured paragraph into the brain dump editor, load the sample, see live word count, and generate organized tasks without registration.
- [ ] The app preserves the original brain dump, does not invent user facts as explicit deadlines, and shows a useful local fallback when AI is unavailable.
- [ ] The organized results screen shows dynamic task counts, priority, estimated workload, deadlines, categories, expandable subtasks, edit/delete controls and completion controls.

## Planning and execution
- [ ] Priorities and “Why this order?” are understandable, overrideable and based on deadline, effort and quick wins.
- [ ] Plan generation respects available time, shows time blocks and breaks, and can be regenerated after progress changes.
- [ ] “Make this easier” creates smaller next steps for an overwhelming task.
- [ ] Focus mode selects the intended task, supports pause/resume, completion and defer actions.
- [ ] Progress updates after completion and a lightweight replan signal is visible when a plan falls behind.

## Navigation, persistence and quality
- [ ] Today, Brain Dump, My Tasks, Focus and History are reachable from responsive desktop/mobile navigation.
- [ ] Drafts, tasks, plans and history persist through refresh; deleted work has a recoverable path where feasible.
- [ ] Visible controls have real actions, keyboard focus is visible, contrast is accessible, and narrow mobile screens remain usable.
- [ ] The reference-inspired visual identity uses the supplied sage/ivory/black/peach direction with Inter and DM Serif Display.
- [ ] `pnpm check` and `pnpm build` pass; `/manus-routes.json` returns valid route metadata; no private keys are exposed to the client bundle.
